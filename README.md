# Welcome to Arya!

This folder contain the server codes of the Arya streaming platform.

# Setup
This server will be running on AWS ECS

## Structure
1. ECS
2. NLB
3. Autoscaling
4. Fargate

## Steps

- Install `docker` and `docker compose`
- To start the server and all dependencies, run `start_full.sh`
- To stop the server and clean up, run `stop_full.sh`
